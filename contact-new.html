📚 Cara Menggunakan:

  1. Salin kode embed yang diinginkan
  2. Tempelkan di file HTML Anda
  3. Ubah URL Tally dengan form Anda sendiri
  4. Deploy ke GitHub Pages untuk mendapatkan link

Tips: Ganti wkKL5r dengan ID form Tally Anda sendiri
